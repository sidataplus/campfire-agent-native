# WP02: native access

Native agents are distinct bot users with no human password, transferable session, legacy bot key or webhook. Explicit room and operator grants are separate. The bearer controller never consumes a browser session. Tokens are displayed only when issued and stored as SHA-256 digests. Deployment flags remain off by default.

The native API has bounded reads, escaped text writes, current room authorization, own-message preconditions, principal-wide idempotency, private staged uploads and authenticated attachment download. Native blobs are denied on the legacy signed URL controllers. WP06 supplies the human UI for native files; no raw signed URL is returned to agents.

Administration is provided by `AgentNative::Administration.change!(human) { ... }` through an authenticated operator console until the WP06 admin surface lands. It serializes with native writes on the instance row. Conversion is explicit and removes legacy keys, sessions, memberships and webhooks. Existing bots are not converted.

This is an implementation candidate, not production qualification. Run `bin/rails db:prepare test` and the stack CI. The framework lockfile is unchanged. WP03 adds replay and explicit invocations; no chat message is an execution request yet.
